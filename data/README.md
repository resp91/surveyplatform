# 지역·성연령 표본 할당표 (n = 10,000)

행정안전부 주민등록 인구통계를 기준으로 전국 표본 1만명을
지역 × 성별 × 연령대 셀에 인구 비례로 배분한 자료와 생성 스크립트.

## 구성

| 경로 | 내용 |
|---|---|
| `population/pop_202512.json` | 원자료 스냅샷. 2025년 12월 주민등록인구, 시도/시군구/읍면동 × 성별 × 5세 단위 연령(0-4 … 100+) |
| `../scripts/build_sampling_quota.py` | 할당표 생성기 |
| `sampling/quota_*_cells_n10000.csv` | 셀 단위 롱 포맷 (지역, 성별, 연령대, 인구, 비중, 이론표본, 배정표본) |
| `sampling/quota_*_by_region_n10000.csv` | 229개 기초지역 × 성연령 와이드 포맷 |
| `sampling/quota_*_by_sido_n10000.csv` | 17개 시도 요약 |
| `sampling/quota_*_by_sexage_n10000.csv` | 전국 성·연령 요약 |
| `sampling/summary_n10000.json` | 위 내용을 묶은 JSON (리포트 페이지가 사용) |
| `sampling/report.html` | 단독 실행되는 열람용 리포트 |

`*` 자리에는 세 가지 연령 기준이 들어간다.

| 키 | 모집단 | 연령대 |
|---|---:|---|
| `age14plus` | 46,321,389명 | 14-19세 / 20대 … 60대 / 70세 이상 (7구간) |
| `all_ages` | 51,117,378명 | 0-9세 / 10대 … 70대 / 80세 이상 (9구간) |
| `adults` | 43,529,812명 | 20대 … 60대 / 70세 이상 (6구간) |

원자료가 5세 단위라 **만 14세는 구간 경계와 맞지 않는다.** `age14plus` 는
'10-14세' 구간 안에서 균등분포를 가정해 그 1/5을 만 14세 인구로 잡고
지역 × 성별로 반올림한다. 실제로는 출생아 감소 때문에 구간 안에서
만 14세가 만 10세보다 조금 많아 참값은 1/5보다 근소하게 크지만,
모집단 비중 차이는 0.1%p 미만이라 배분 결과는 사실상 같다.

## 지역 구분

- 특별시·광역시 → 자치구 및 군 (예: 서울특별시 종로구, 부산광역시 기장군)
- 도·특별자치도 → 시·군 (예: 경기도 성남시)
- 세종특별자치시 → 단일 지역

일반구 35개(성남시 분당구, 창원시 마산합포구 등)는 상위 시로 합산하고,
인구 0인 출장소 2개(경기 북부출장소, 강원 동해출장소)는 제외한다. 총 229개 지역.

원자료의 `name` 필드 들여쓰기가 계층을 나타내므로(1칸 = 기초, 2칸 = 일반구)
이를 기준으로 분리하며, 229개 지역의 합이 시도 합계·전국 합계와
성별 5세 연령 전 셀에서 일치하는지 실행 시마다 검증한다.

## 배분 방식

셀 이론값은 `n × (셀 인구 ÷ 모집단 인구)`. 정수화는 최대잔여법으로 하되
세 주변합을 모두 통제한다.

1. 시도 목표치 — 17개 시도 인구비례 (합 = n)
2. 지역 목표치 — 각 시도 안에서 시군구 인구비례 (합 = 시도 목표치)
3. 성연령 목표치 — 전국 성 × 연령 인구비례 (합 = n)
4. 1차 배분 — 각 지역 배정량을 그 지역 고유 성·연령 구성비로 배분
5. 보정 — 전국 성연령 합계가 어긋난 만큼만 같은 지역 안에서 과잉 셀 −1 / 부족 셀 +1 맞교환
   (이론값 대비 제곱오차 증가가 가장 작은 지역 선택)

결과적으로 시도 합계, 229개 지역 합계, 전국 성·연령 합계, 그리고 개별 셀까지
모두 인구 비례 이론값과 ±1명 이내로 일치하고 총합은 정확히 n이 된다.

셀 단위로 최대잔여법을 한 번만 적용하면 울릉군(이론값 1.7명)처럼 셀이 잘게 쪼개진
소규모 지역이 0명이 되고, 보정 없이 지역별로만 배분하면 전국 성연령 합계가
목표치에서 20명 이상 밀린다. 위 절차는 두 왜곡을 모두 없앤다.

## 실행

```bash
python3 scripts/build_sampling_quota.py            # n = 10,000
python3 scripts/build_sampling_quota.py -n 2000    # 다른 표본 크기
python3 scripts/build_sampling_quota.py --schemes age14plus   # 특정 기준만
```

표준 라이브러리만 사용한다.

## 한계

- 셀 수가 표본 1만명보다 많아 모든 셀을 채울 수 없다.
  0명 셀은 `age14plus` 528개, `all_ages` 852개, `adults` 354개. 실사에서는 시도×성×연령으로 할당을 묶고
  시군구는 목표 분포로 관리하는 편이 현실적이다.
- 만 18·19세를 따로 떼는 기준(만 19세 이상 등)은 5세 단위 원자료로 만들 수 없다.
  1세 단위 원자료가 있어야 한다.
- 원자료는 2025년 12월 스냅샷이다. 최신 월로 갱신하려면
  행정안전부 주민등록 인구통계(jumin.mois.go.kr)에서 같은 구조의
  JSON을 만들어 `population/` 에 넣고 `--src` 로 지정한다.
